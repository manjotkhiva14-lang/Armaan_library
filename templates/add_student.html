Quick Guidelines

Creating a unique student record allows the database to instantly prevent duplicate seat allocations across overlapping daily shifts.

  • Unique ID Rule: Ensure the assigned ID does not conflict with active allocations.
  • Shift Lock: The preferred shift choice serves as the default suggestion during automated seat allotments.
  • Updates: Student profiles can be updated or released later via the "Manage Seat" control portal.
Note: Make sure the Student ID matches their official library card number to allow hassle-free seat check-ins later.
